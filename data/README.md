# Datasets and experiment results

Raw and processed datasets, predictions, evaluation scores and fitted models, grouped by experiment round. catalog.json lists the retained files and their checksums.

Absolute paths in public experiment records use a generic user directory. Checksums embedded in historical records describe the recorded artifacts; `catalog.json` gives the current checksums of the retained files.
